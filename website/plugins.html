1. Build with Go, then install

  -o ./trawl-beeper ./cmd/trawl-beeper

trawl plugin install ./trawl-beeper \
  --allow-self-hosted 127.0.0.1:23373=127.0.0.1/32 \
  --allow-read-secret beeper_access_token \
  --allow-write-secret beeper_access_token

No access by default External plugins run inside a macOS sandbox with zero network, folder, or Keychain access until you approve each permission explicitly.
Isolated per app A plugin writes only to its own archive folder and can never read your messages, mail, or any other OpenTrawl archive.
Hash-pinned binaries OpenTrawl pins each installed plugin's SHA-256 hash. If an update changes the binary or asks for new access, it stops and asks you again.
