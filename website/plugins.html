Sources & Plugins

OpenTrawl ships with 12 built-in sources and supports standalone plugins for any other app, API, or export.

How plugin permissions work: Every external plugin runs inside a macOS sandbox with no network, file, or Keychain access by default. Before installing a plugin, you approve the exact folders, websites, and credentials it declares. OpenTrawl pins the binary's SHA-256 hash and blocks any update that asks for new access until you approve it again.
