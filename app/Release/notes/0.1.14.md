Twitter (X) is now enabled in OpenTrawl with two explicit read-only sync
options: a free browser session cookie connection (`trawl twitter connect`) and
the existing official X API v2 backend. Both archive bookmarks, likes, authored
tweets, and mentions into the same local store, and browser session connections
also archive X direct messages (both accepted conversations and message
requests).

X direct messages integrate with `trawl conversations`, `trawl messages`,
`trawl search`, `trawl open`, `trawl who`, and OpenTrawl People. Browser session
syncs use incremental stop-at-known-record paging, a 15-minute cooldown, and
persisted per-endpoint rate-limit windows to keep request volume low and avoid
rate-limit exhaustion. OpenTrawl never falls back silently between free session
cookies and the paid official API.
