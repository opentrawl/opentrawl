Money can now keep multiple Enable Banking connections current, including Wise,
with an independent daily read limit for each. Wise balances, transfers, fees
and pending activity use the same accounts, transactions, search and open views.
Retained statement history can join the live feed without counting transfers
or fees twice.

Connections require an existing read-only consent and accounts bound to stable
identities. Imported statement coverage stays visible; a live read does not
imply that every earlier transaction is available.
