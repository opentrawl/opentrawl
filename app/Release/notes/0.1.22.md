# OpenTrawl 0.1.22

## Highlights

- **Redesigned Mac app and full-bleed Photos viewer:** Native macOS split-view workspace with weekly activity timelines, clean conversation and sender names, green own-message bubbles, fixed Settings without Keychain prompts, and a full-bleed Apple Photos viewer with fast on-demand Apple PhotoKit loading, persistent caching, zoom, and a collapsible Info inspector.
- **In-app Tailscale archive server:** Share your local archive read-only with another Mac or iOS client directly from Settings → Other Macs inside `OpenTrawl.app`, with source-scoped tokens, verified Tailscale transport, and strict cross-source isolation.
- **MCP server with Skills over MCP and Personal Wiki:** Connect AI agents over stdio or Tailscale Streamable HTTP with ProtoJSON `structuredContent`, resized photo image delivery in `trawl_open`, and built-in **Skills over MCP** (`skill://opentrawl/SKILL.md` and `skill://personal-wiki/SKILL.md`), plus a one-click **Build Personal Wiki** prompt button in the Mac app.
- **Faster search, cleaner sources, and direct Telegram API sign-in:** Up to 25× faster `trawl open`, native Apple Photos indexing in `index.db`, fixed Calendar all-day dates, X author titles and expanded links (noting classic DMs only), and zero-Full-Disk-Access Telegram sign-in with OpenTrawl's own API credentials, incremental sync, `--fetch-media`, clear 2FA errors, and `--password-file`.
