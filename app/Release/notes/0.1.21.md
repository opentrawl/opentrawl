# OpenTrawl 0.1.21

## Highlights

- **Optional local semantic search (`trawl semantic`):** Add opt-in session-chunked hybrid topic search powered by a native Apple Silicon Swift/MLX embedding helper (`trawl-embed` with `Qwen3-Embedding-0.6B` downloaded on demand and SHA-256 verified) and a separate, disposable `semantic.db` index over `index.db` — zero Python runtime, 0 MB idle memory, and automatic fallback to Layer 1 lexical search when disabled.
- **Four more standalone sandboxed plugins:** Move `twitter`, `whatsapp`, `telegram`, and `notes` out of the core `trawl` binary into signed bundled plugin executables (`trawl-twitter`, `trawl-whatsapp`, `trawl-telegram`, `trawl-notes`) with strict least-privilege macOS Seatbelt profiles (offline read-only container access for local apps; allowlisted proxy hosts for `twitter`).
- **Staged external plugin CLI (`trawl plugin`):** Add `trawl plugin list`, `trawl plugin install`, and `trawl plugin remove` with SHA-256 binary pinning and host-owned `trust.pb` approvals, including explicit self-hosted CIDR exemptions for Tailscale and LAN services.
