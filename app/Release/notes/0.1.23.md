# OpenTrawl 0.1.23

## Highlights

- **Twitter/X sync works again:** X changed its web client, and OpenTrawl then wrongly reported that X no longer accepted a valid session. Updates stopped and `trawl status twitter` showed `works: no`. OpenTrawl now finds X's account check in the new web client again, and a changed or missing X endpoint no longer marks your session as signed out. If Twitter shows `works: no` after this update, reconnect once with `trawl twitter connect`.
