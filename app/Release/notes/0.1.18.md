# OpenTrawl 0.1.18

## Highlights

- **Standalone plugin runtime and macOS sandbox:** Run external and bundled OpenTrawl crawlers as isolated executables speaking raw length-delimited binary protobuf, with per-invocation macOS Seatbelt profiles, an isolated Data Protection Keychain secret broker, and an allowlisted loopback HTTP `CONNECT` proxy supporting explicit self-hosted network exemptions.
- **Money as the first standalone bundled plugin:** Move `money` out of the core `trawl` binary into a standalone bundled plugin executable (`trawl-money`) with full support for `trawl money`, `trawl status`, `trawl search`, `trawl open`, `trawl around`, `trawl update`, incremental index exports, and the Mac app.
