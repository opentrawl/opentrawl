# OpenTrawl 0.1.17

## Highlights

- **Unified cross-archive search index:** Add a local derived search index (`index.db`) that powers fast global search across your archived sources with shared BM25 ranking, recency weighting, and conversation collapse, updated incrementally during `trawl update` and manageable with `trawl index status` and `trawl index rebuild`.
- **Cross-source context with `trawl around`:** Explore related records across sources around any record link, date, window, or trip, including mechanical matches between financial transactions and receipts or booking messages.
- **Unified plugin index export contract:** Stream typed index changes and short-reference updates from crawlers into the core index atomically without reading private crawler databases, while preserving existing short-reference links verbatim.
