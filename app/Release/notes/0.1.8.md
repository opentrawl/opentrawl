OpenTrawl now runs as a single signed macOS binary, with `trawl` pointing
straight into the app bundle so the CLI and app share one identity and one
Keychain access group.

Gmail now connects directly to the Gmail API with read-only OAuth, hardware
Secure Enclave DPoP binding and Data Protection Keychain storage, and stores
compressed raw message originals alongside the local index. A new Apple Mail
trawler archives local Mail.app stores (such as iCloud Mail) read-only without
touching Mail.app's files.
